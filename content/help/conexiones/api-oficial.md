Hoy Auream conecta tus números con **código QR**. La conexión por la **API oficial de WhatsApp** (de Meta) llega más adelante.

## Qué cambiará

- Para escribirle primero a un cliente (difusiones), la API oficial exige **plantillas aprobadas por Meta**.
- Los grupos por la API oficial también llegarán después.

Mientras tanto, las difusiones y los grupos funcionan con tus números conectados por QR.
